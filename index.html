🌐 How to Host This Project on GitHub Pages

✨ Free Hosting: GitHub Pages lets you host static websites directly from your GitHub repository for free!

Step 1: Push Your Code to GitHub

Ensure your local code (including index.html) is committed and pushed to GitHub:

git add .
git commit -m "Add Web Interface and GitHub Pages support"
git branch -M main
git remote add origin https://github.com/<your-username>/Digital-Secure-File-Sharing.git
git push -u origin main

Step 2: Enable GitHub Pages in Repository Settings

  1. Go to your GitHub repository: https://github.com/<your-username>/Digital-Secure-File-Sharing
  2. Click on the Settings tab at the top right of the repository.
  3. In the left sidebar, click on Pages (under Code and automation).
  4. Under Build and deployment > Source, select Deploy from a branch.
  5. Under Branch, select main branch and / (root) folder.
  6. Click Save.

Step 3: Access Your Live Hosted Website

After 1-2 minutes, GitHub will publish your live website at:
https://<your-username>.github.io/Digital-Secure-File-Sharing/
